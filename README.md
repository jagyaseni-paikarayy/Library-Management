Library Management System

About the Project

The Library Management System is a web-based application developed using Spring Boot. It provides a simple interface for managing course records.

Features

- View all courses
- Add new courses
- Delete courses (if implemented)
- Frontend and backend integration

Technologies Used

- Java
- Spring Boot
- HTML
- CSS
- Maven

How to Run Locally

3. Run the Spring Boot application.
4. Open "http://localhost:8080/" in your browser.
